# Akan Name Generator

## Description

The Akan Name Generator is a web application that allows users to discover their Akan name based on their birth date and gender.

Akan names originate from Ghanaian culture, where children are traditionally named according to the day of the week they were born.

The application validates the user's input, calculates the day of the week using a mathematical formula, and displays the corresponding Akan name.

---

## Features

- Enter birth day, month, and year.
- Select gender.
- Validates user input.
- Detects invalid calendar dates.
- Prevents future birth years.
- Calculates the day of the week.
- Displays the correct Akan name.

## How to Use

1. Open the project in your browser.
2. Enter:
   - Day
   - Month
   - Year
   - Gender
3. Click **Generate Akan Name**.
4. Your Akan name and the day you were born will be displayed.

---

## Validation

The application checks that:

- All fields are filled.
- Day is between 1 and 31.
- A valid month is selected.
- The year is not greater than the current year.
- The entered date exists on the calendar.
- A gender has been selected.
